Code Sample: Earnings Data Pipeline


import pandas as pd
from sqlalchemy import create_engine

# Connect to earnings database
engine = create_engine("postgresql://user:password@host:5432/fin_db")

# Load quarterly earnings data
df = pd.read_sql("SELECT * FROM quarterly_earnings", engine)

# Simple analytics
df["net_margin"] = df["net_income"] / df["revenue"]

# Filter latest quarter
latest_q = df.sort_values("quarter").tail(1)
print(latest_q[["quarter", "revenue", "net_income", "net_margin"]])
Highlight how we use a Python data pipeline to extract earnings data directly from our analytics database, compute net margin, and filter for the latest quarter. Mention that RevealJS provides syntax highlighting and line-by-line focus via data-line-numbers.

Financial Formulas

Return on Equity (ROE):

\[ \text{ROE} = \frac{\text{Net Income}}{\text{Shareholder's Equity}} \]

Net Present Value (NPV):

\[ \text{NPV} = \sum_{t=0}^{T} \frac{C_t}{(1 + r)^t} \]

Compound Annual Growth Rate (CAGR):

\[ \text{CAGR} = \left(\frac{V_{\text{final}}}{V_{\text{initial}}}\right)^{\tfrac{1}{n}} - 1 \]
